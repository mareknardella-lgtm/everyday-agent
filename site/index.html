The Problem

Another chatbot isn't the answer.

People don't need more notifications. They need something that handles repetitive work without creating anxiety. Fixed thresholds don't work — you trust your plumber for €300 but not a new provider for €20.

⊘

Fixed thresholds fail

"Above €50, ask" is a rule that treats every provider and every context the same. It doesn't reflect real trust.

ༀ

Notifications create anxiety

Every approval request is a decision. More decisions = more mental load. The opposite of what an agent should do.

◫

No explainability

When the agent acts on its own, you can't ask why. Opacity destroys trust. Without trust, you disable everything.

The Dynamic Trust Engine

One trust score per combination.

Not a fixed threshold. A continuous 0–100 score for every combination of action + counterparty + context. It starts cautious and self-calibrates through your real interactions.

New provider 20/100

Faucet repair · New plumber · First time

→ Agent asks for confirmation
Known provider 65/100

Monthly electricity · Same provider · 12 approvals

→ Agent informs in digest
Trusted combo 92/100

Grocery order · Usual store · Weekly

→ Agent executes silently (within cap)
◈
Safety caps are absolute

Money, health and legal documents always have hard ceilings — even with trust 100/100. The trust engine never overwrites these protections.
